Knowledge Base

LLM Wiki 知识库

基于 Karpathy LLM Wiki 模式，三层架构实现知识的获取、提炼与结构化管理

LAYER 1
Raw 素材层

不可变原始素材 — URL 抓取、PDF、对话记录、手写笔记。Agent 只读，带 SHA256 校验。

wiki/raw/{domain}/
LAYER 2
Derived 知识层

Agent 管理的知识页面 — 实体、概念、对比分析。YAML frontmatter + Wikilinks。

wiki/实体/ · 概念/ · 对比/
LAYER 3
Schema 规范层

结构定义与标签分类体系。SCHEMA.md 是 Agent 间交接协议，任何 Agent 读取即可接管。

wiki/SCHEMA.md

3
Content Pipeline

内容创作流水线

三阶段流水线：碎片化输入 → 结构化输出 — 降低写作启动门槛，消除空白文档焦虑

STAGE 1
Essay Dialog

对话式思考记录。AI 角色 = 有准备的对话者，参与碰撞而非代笔。记录思考过程，而非产出结论。

wiki/raw/{domain}/essay-topic.md
STAGE 2
Article

从现有素材产出结构化文章。AI 采访、提取、结构化。叙事结构：困境 → 碰壁 → 意外解法 → 升级。

wiki/raw/{domain}/descriptive-title.md
STAGE 3
WeChat Publish

Markdown → Kami 风格 HTML → 微信草稿。自动配图（matplotlib），支持封面 + 内嵌图片上传。

API: draft/add → 手动发布
微信公众号发布管道
飞书语音 → AI 累积 → 生成初稿 → 用户审校 → matplotlib 配图 → HTML 转换 → 微信草稿
• HTML 转换器：Kami 风格排版（section headers + editorial quotes + callout boxes）
• 约束：标题 ~10 中文字，摘要 ~12 字，正文无外链（仅「阅读原文」）
• 核心价值：AI 是编辑不是代笔，碎片化输入 → 结构化输出
